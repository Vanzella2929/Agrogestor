# Projeto Software Agro - Custo de Produção de Vaca Parida e Cria

## Sobre o Projeto

Este sistema tem como objetivo auxiliar produtores rurais no controle do custo de produção de vacas paridas e cria, permitindo o cadastro de animais, despesas, receitas e relatórios para facilitar a tomada de decisões.

## Problema

Muitos produtores realizam o controle dos custos manualmente, dificultando a análise financeira e aumentando as chances de erros.
