# Projeto Agrogestor

## Sobre o Projeto

O Agrogestor é um sistema desenvolvido para auxiliar produtores rurais no controle dos custos de produção de vacas paridas e cria.

O sistema terá como objetivo facilitar o cadastro e o acompanhamento de:

Animais
Pesagens
Insumos
Despesas
Receitas
Custos de produção
Relatórios

A ideia é substituir parte dos controles feitos manualmente, ajudando o produtor a visualizar melhor seus gastos e tomar decisões.

## Problema
Muitos produtores rurais ainda realizam o controle dos custos de produção de forma manual, utilizando anotações, cadernos ou planilhas.

Isso pode dificultar:

O controle dos gastos;
A organização das informações;
O cálculo dos custos;
A análise dos resultados;
A tomada de decisões.

O Agrogestor busca organizar essas informações em um único sistema.
